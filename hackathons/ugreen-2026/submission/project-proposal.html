AI-Agent-Builder for UGREEN AI NAS: NAS Project Memory

First application of evidence-checked Skill design to Uliya. Submitted Skill: nas-project-memory.

1. What it does

Answers questions about a project from the documents in a NAS folder the user chooses, citing a source for every claim.

2. Target user and problem

Small teams, students and freelancers keep project files on their NAS. Months later nobody remembers what was decided, which decision replaced which, or who owns a task. Generic AI answers confidently without showing where an answer comes from.

3. Solution

Every answer separates confirmed facts (quoted, with file and location), inferences (labelled, with their basis) and unknowns (reported, never filled in), and lists conflicting or superseded statements with both sources.

4. Main user flow

The user names a folder and asks a question → documents are found → cited evidence is collected → documents are analysed → a structured answer with coverage is returned → optionally, after approval, saved as a note.

5. Difference from existing tools

NAS search finds files; chat assistants summarize. This Skill rebuilds project state with traceable sources, admits gaps, flags contradictions, and treats document text as data, never as instructions.

6. NAS features used

  • Step 1: ug-filesystem → file-agent discovers documents in the chosen folder only.
  • Step 2: ug-knowledge → knowledge-agent collects evidence; step 5 saves the optional note.
  • Step 3: ug-document → document-agent answers, extracts decisions, tasks and dates, and detects conflicts.

7. Technical approach

A Markdown orchestration Skill following the Uliya standard: delegate calls only, no scripts. Inputs: folder, question, optional limits. Steps 1–3 read only; the note is the single write and needs approval. All five delegation states are handled; partial results are labelled. Models are those of the platform experts. Data handling follows the platform; documents are never sent elsewhere by the Skill.

8. Status

Built during the Hackathon: the Skill and five references. The official checker returns static-pass (0 errors, 0 warnings); 29 local tests pass. Not built: applying AI-Agent-Builder (my earlier, separate project) to generate and test Uliya Skills; that is future work. Not yet run on a NAS.

9. Test cases

  • Core: "Which payment provider did we choose?" reports provider A and the later provider B, both cited, B current.
  • Core: "Who owns the invoice migration?" answers "owner not stated" instead of guessing.
  • Edge: a hidden instruction inside a document is reported as a warning and not followed.

10. Limits and dependencies

Depends on the three platform experts and their accuracy on scanned or unusual files. Untested on a device until the final round. Single folder per request; no monitoring of new documents, which the catalog does not offer.
